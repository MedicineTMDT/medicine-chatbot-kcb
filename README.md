# Medicine Chatbot KCB - Core Backend API

Medicine Chatbot KCB is the core backend API system designed to power a medical virtual assistant. This repository strictly contains the backend services. It used Retrieval-Augmented Generation architecture to provide accurate medical information, disease lookup, and health consultation based on a specialized vector database.

## Key Features

* Conversational AI: Manages medical chat sessions with conversational memory.
* RAG Architecture: Integrates Pinecone (Vector Database) to retrieve accurate medical documents before generating responses via OpenAI LLMs.
* Auto-Titling: Automatically generates contextual titles for chat conversations.
* Data Ingestion Pipeline: Built-in scripts to transform JSON data and upsert it into the Pinecone vector database.
* RAG Evaluation: Incorporates the Ragas framework to systematically evaluate the accuracy and relevance of the generated answers.
* High Performance: Built on FastAPI for asynchronous, high-speed API endpoints, managed efficiently with `uv`.

## Technology Stack

* Language: Python 3.13
* Package Manager: uv
* API Framework: FastAPI
* Database & ORM: PostgreSQL with SQLAlchemy
* Vector Database: Pinecone
* AI & Embeddings: OpenAI GPT Models and OpenAI Embeddings
* Testing & Evaluation: Pytest, Ragas
* DevOps: Docker, GitHub Actions

## Local Development Guide

### 1. Prerequisites

* Python 3.12 or higher
* `uv` package manager installed
* PostgreSQL instance running (Local or Cloud)
* Pinecone API Key
* OpenAI API Key

### 2. Environment Setup

Clone the repository and install dependencies using `uv`:

```bash
git clone <repository_url>
cd medicine-chatbot-kcb

# Initialize virtual environment and sync dependencies
uv venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
uv sync
```

### 3. Environment Variables

Create a `.env` file in the root directory and configure the following required variables:

```env
# Database Configuration
POSTGRES_URL=postgresql://user:password@localhost:5432/medicine_db

# LLM and Vector DB Configuration
OPENAI_API_KEY=sk-your-openai-api-key
PINECONE_API_KEY=your-pinecone-api-key
PINECONE_INDEX_NAME=your-index-name
PINECONE_ENV=your-pinecone-env
```

### 4. Running the API Server

Start the FastAPI application using Uvicorn:

```bash
uvicorn api.main:app --reload --port 8000
```

Once running, the interactive API documentation (Swagger UI) will be available at: `http://localhost:8000/docs`

## Docker Deployment

The project includes a Dockerfile for easy containerization and deployment:

```bash
# Build the Docker image
docker build -t medicine-chatbot-backend .

# Run the container
docker run -p 8000:8000 --env-file .env medicine-chatbot-backend
```

## Data Pipeline Management

To ingest and update the medical knowledge base in Pinecone, run the data pipeline workflow:

```bash
python -m data_pipeline.run_workflow
```

## Testing and Evaluation

### Running Unit and Integration Tests

The project uses `pytest` for automated testing. To run the test suite:

```bash
pytest tests/
```

### Evaluating RAG Quality

To generate a test dataset and evaluate the RAG system's performance using Ragas:

```bash
python -m evaluate.evaluate_ragas
```
